# 📸 CR2 to JPG/PNG Web Converter

A modern, privacy-focused web application that allows photographers to convert **Canon RAW (.CR2)** files to **JPG or PNG** directly in the browser — no uploads, no servers, no heavy software.

---
https://leofom.github.io/CR2-to-JPG-PNG-converter/
---

## 🌍 Live Concept

**Client-side only.**
All processing happens locally using **JavaScript + WebAssembly**, ensuring:

* 🔒 Full privacy
* ⚡ High performance
* 🌐 Offline capability
* 🚫 Zero server dependency

---

## 🚀 Features

### ✅ Zero Server Uploads

All image processing runs directly in your browser. Files never leave your device.

### 📂 Drag & Drop Support

Simply drop your `.CR2` files into the interface.

### 🗂 Batch Processing

Convert multiple RAW files simultaneously.

### 📊 Smart UI Feedback

* 🟢 Green progress bar — success
* 🔴 Red progress bar — error

### 🗜 ZIP Export

Download all converted images in a single archive.

### 🕘 Local Session History

Stores the last **8 conversions** using browser storage.

### 🌐 Multilingual Interface

* 🇺🇦 Ukrainian
* 🇬🇧 English

---

## 🛠 Tech Stack

### Frontend

* HTML5
* Tailwind CSS

### Logic

* Vanilla JavaScript (ES6+)
* WebAssembly (WASM)

### Libraries

* UTIF.js — RAW/TIFF decoding
* JSZip — ZIP archive generation
* LocalStorage — session persistence

# 📸 Веб-конвертер CR2 у JPG/PNG

Сучасний безсерверний веб-застосунок для фотографів, що дозволяє конвертувати **Canon RAW (.CR2)** у **JPG або PNG** прямо у браузері — без встановлення програм і без завантаження файлів на сервер.
